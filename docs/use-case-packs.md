# Use‑Case Packs

MCP packs bundle tools that can be discovered and invoked by agents. They enable a wide range of functionality, from data look‑ups to UI generation.

## Generative UI Pack

The **example‑pack** includes a tool that demonstrates the Generative UI contract described in [Generative UI Authoring Guide](./mcp-generative-ui.md).

* `show‑logo` – returns an image widget.
* `show‑chart` – returns a chart widget.

See the pack source code in `packs/example-pack/`.
